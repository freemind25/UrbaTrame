URBATRAME — INSTALLATION (1.0.1)

Ces applications ouvrent la version publique d’UrbaTrame et nécessitent une connexion Internet :
https://freemap-rose.vercel.app

L’onglet « Atelier d’analyse urbaine » présente le suivi des 14 séances (S1–S14), avec statuts, notes locales et export JSON. Il est intégré à UrbaTrame.

WINDOWS
Fichier : windows/UrbaTrame-Setup-1.0.1.exe
Système : Windows 10/11, 64 bits.
1. Téléchargez et ouvrez l’installeur.
2. Choisissez une installation pour votre compte et, si souhaité, créez le raccourci du Bureau.
3. Au premier lancement, Windows peut afficher SmartScreen car l’installeur n’a pas de signature de certificat commercial. Vérifiez le nom du fichier avant de continuer.

ANDROID
Fichier : UrbaTrame-Android.apk
Système : Android 10 ou plus récent.
1. Téléchargez l’APK sur le téléphone et ouvrez-le depuis Téléchargements.
2. Si Android le demande, autorisez temporairement l’installation depuis l’application utilisée pour ouvrir le fichier.
3. Appuyez sur Installer, puis ouvrez UrbaTrame.
Les exports créés dans l’application sont enregistrés dans Téléchargements/UrbaTrame.

L’APK 1.0.1 est signé pour installation directe et test, pas pour publication sur Google Play. Il utilise une clé de test différente de l’ancienne APK. Si Android signale une signature différente de la version précédente, il faudra désinstaller celle-ci avant l’installation; les données locales de l’application peuvent alors être supprimées. Les notes et autres données du navigateur restent enregistrées sur l’appareil.
